# Docs

このフォルダは、アプリの公開用成果物を保存するためのディレクトリです。

---

## 役割

- `wrgg-frontend` のビルド結果を配置する
- GitHub Pages で公開する HTML / CSS / JS を保存する
- デプロイ済みの静的サイトを格納する

---

## 重要なポイント

- このディレクトリは「ソースコード」ではなく「生成物」であることが多いです
- 手で編集するより、ビルドコマンドで再生成するのが基本です
- `wrgg-frontend` の `npm run build` または `npm run build-docs` の成果物がここに配置されます

---

## 実際の運用

```bash
cd wrgg-frontend
npm run build-docs
```

生成されたファイルは `docs/` 配下に出力され、GitHub Pages から参照されます。

---

## 触るときの注意

- ビルド前に `wrgg-frontend` の設定やデータを確認する
- 生成物はコミット対象になることがあるため、更新前後を確認する
- ここにある内容は公開サイトにそのまま反映されるため、意図しない差分がないかを確認する

---

## 目安

- 開発元のコードは `wrgg-frontend/src/`
- 公開用の静的サイトは `docs/`
- こうした役割分担を明確にしておくと、保守しやすくなります
